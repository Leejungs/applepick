# 애플픽(ApplePick) 발표 시나리오 & 대본

- 슬라이드: [애플픽_발표자료.pdf](애플픽_발표자료.pdf) (15장)
- 총 **약 10분** = 발표 6분 + 라이브 시연 4분 (질의응답 별도)
- 역할 예시: **발표자 A**(문제·니즈·가치), **시연자 B**(라이브 시연·기술), 필요하면 **C**(질의응답 백업)
- 대본의 `▶` 는 화면 조작, `★` 는 심사위원에게 짚어 줄 평가표 항목입니다.

## 1. 표지 · 20초 (발표자 A)

> 안녕하세요, [팀명]의 [이름]입니다.
> 저희가 만든 서비스는 **애플픽**, 흩어진 중고 애플 매물을 한 번에 찾고, AI에게 "이거 사도 돼?"라고 물어볼 수 있는 서비스입니다.

## 2. 문제 인식 · 50초 (A)

> 중고 애플 제품을 사 보신 분이라면 세 가지가 불편하셨을 겁니다.
>
> 첫째, **플랫폼이 나뉘어 있습니다.** 번개장터, 당근, 중고나라를 번갈아 봐야 하고, 번개장터에서 '맥북'만 검색해도 매물이 3,700건이 넘습니다. 저희가 직접 측정한 숫자입니다.
>
> 둘째, **적정 가격을 알기 어렵습니다.** 같은 모델이라도 용량, 배터리 상태에 따라 가격이 제각각이고, 부품이나 미끼 매물이 섞여 있습니다.
>
> 셋째, **사기 위험**입니다. 시세보다 지나치게 싼 가격, 선입금 요구, 카톡으로 옮기자는 말. 경험이 적은 사람은 알아채기 어렵습니다.

★ 발표 구성: 문제 인식의 타당성

## 3. 사용자 니즈 · 50초 (A)

> 저희는 두 명의 가상 사용자를 설정했습니다.
>
> **민지**는 공대 4학년으로, 예산 90만 원으로 아이폰을 바꾸고 싶지만 중고거래 경험이 거의 없습니다. "이 가격이 싼 건지 사기인 건지 모르겠다"는 게 민지의 고민입니다.
>
> **현승**은 32세 개발자로, 쓰던 맥북 에어를 팔려고 합니다. "지금 시세가 내려가는 중인지, 지금 파는 게 나은지" 알고 싶어 합니다.
>
> 여기서 **예산 안의 매물, 적정가 판단, 사기 여부 확인, 시세 추이, 가격 알림**이라는 니즈를 도출했습니다.

★ 사용자 니즈 분석: 페르소나 기반 니즈 도출
(실제 지인 인터뷰를 했다면 한 문장 추가: "주변 ○명에게 물어보니 ○명이 사기 걱정을 가장 크게 꼽았습니다.")

## 5. 라이브 시연 · 4분 (시연자 B)

> 시연 중 AI 답변은 **10~15초** 걸립니다. 기다리는 동안 화면에 뜨는 **의도 배지와 도구 칩**을 가리키며 설명하면 공백이 생기지 않습니다.

### 5-1. 통합 검색 (40초)
▶ 탭 ① 메인 → **iPhone** → **iPhone 15 Pro** 클릭

> 카테고리와 모델을 고르면 여러 마켓의 매물이 모입니다. 위에는 최근 7일 **평균 시세와 최저가**가 나오고, 카드마다 어느 마켓 매물인지 표시됩니다.
> 시세는 z-score로 허위·미끼 가격을 걸러낸 값입니다.

▶ 상단 **가격추이** → 모델 선택 → 4주 그래프 (10초)

### 5-2. AI 어시스턴트 (3분 20초)
▶ 탭 ③ `/assistant`. 질문은 **복사해 둔 문장을 붙여 넣으면** 오타가 없습니다.

**① 매물 찾기 · 자체 Tools**
```
아이폰 15 프로 90만원 이하 매물 찾아줘
```
> AI가 먼저 질문 **의도를 '매물 찾기'로 분류**하고 예산 90만 원을 뽑아냈습니다.
> 이어서 **상품 찾기 → 매물 검색 → 시세 분석** 도구를 스스로 골라 실행합니다. 이 도구들은 저희가 직접 만든 함수입니다.
> 결과는 실제 번개장터 매물 카드로 나오고, 누르면 원래 매물로 이동합니다.

★ 자체 Tools 2개 이상 / 사용자 입력에 맞는 기능

**② 사기 신호 탐지 · 분류**
```
에어팟 프로 2를 13만원에 판다는데 괜찮아? 설명에 '카톡으로 연락 주세요, 선입금 시 예약'이라고 써 있어
```
> 가격만 보면 시세보다 20% 싸서 '매우 저렴'으로 분류됩니다.
> 하지만 빨간 배지를 보시면 **선입금 요구, 외부 메신저 유도**라는 사기 신호를 잡아냈습니다. 그래서 AI는 "가격은 좋지만 거래는 조심하라"고 답합니다.

★ 기술 통합: 검색·평가·분류·요약이 한 흐름으로

**③ RAG**
```
중고 아이폰 살 때 꼭 확인해야 할 것 알려줘
```
> 이번에는 매물 검색 대신 **가이드 검색 도구**만 썼습니다. 저희가 만든 구매 가이드 문서를 검색해서 근거로 답하는 **RAG**입니다. 아래 칩이 참고한 문서입니다.

★ RAG

**④ 인터넷 검색**
```
아이폰 17 출시 가격 찾아보고 지금 중고 시세랑 비교해줘
```
> 출시 가격은 저희 데이터에 없으니 **웹 검색**을 합니다. 애플 공식 사이트를 출처로 인용하고, 저희가 수집한 중고 시세와 비교해 줍니다.

★ 인터넷 검색

**⑤ 음성 + 자동화**
▶ 🎙️ 마이크 버튼을 누르고 말하기
```
맥북 에어 80만원 이하 매물 나오면 알려줘, 이메일은 (본인 이메일)
```
> 음성으로 말해도 됩니다. AI가 **알림 등록 도구**를 실행했고, 이제 크롤러가 새 매물을 수집할 때 조건에 맞으면 이메일이 갑니다.

★ 음성 기능 / 자동화

**⑥ 분기 처리 (짧게)**
```
오늘 날씨 어때?
```
> 서비스와 무관한 질문은 첫 단계에서 걸러서 도구를 쓰지 않고 안내합니다. 이게 LangGraph의 **조건 분기**입니다.

▶ 슬라이드로 복귀 (8번)

## 6. 시스템 구조 · 40초 (B) — 슬라이드 8

> 전체 구조는 단순합니다. 크롤러가 매물을 수집해 저장하고, Flask API가 검색과 시세를 제공하고, React 웹이 보여줍니다.
> AI 어시스턴트는 API 안에서 **같은 데이터를 도구로 사용**하고, 진행 상황을 실시간으로 화면에 보냅니다.
> Docker로 전체를 한 번에 배포할 수 있고, 발표용으로는 설치 없이 실행되는 데모 모드와 Vercel 배포도 준비했습니다.

★ 창의성·확장성: 배포가 쉬운 형태

## 7. AI 구조 · 50초 (B) — 슬라이드 9

> AI는 **LangGraph**로 만든 에이전트입니다.
> 질문이 들어오면 **analyze** 노드가 의도·제품·예산을 구조화해서 뽑고, 관련 없는 질문이면 **decline**으로 보냅니다.
> 아니면 **agent** 노드에서 LLM이 필요한 도구를 고르고, **tools** 노드가 실행한 결과를 다시 agent에 넘기는 과정을 답이 나올 때까지 반복합니다.
> LLM 호출, 도구 정의, 검색기 모두 **LangChain**으로 구현했습니다.
> 특히 신뢰성을 위해 가격과 매물 숫자는 반드시 도구 결과만 쓰게 했고, 샘플 데이터가 섞이면 AI가 스스로 밝히게 했습니다.

★ LangChain 및 LangGraph

## 8. 기술 적용 · 30초 (B) — 슬라이드 10

> 정리하면 자체 도구가 **여섯 개**, 여기에 **RAG**와 **인터넷 검색**이 더해져 있습니다. 시연에서 보신 것처럼 질문에 따라 이 중 필요한 것만 조합해서 씁니다.

(슬라이드 11 '시연 시나리오'는 시연을 마쳤으므로 **넘어가거나 5초만** 보여줍니다.)

## 9. 공공성과 상업성 · 40초 (A) — 슬라이드 12

> 애플픽의 가치는 두 가지입니다.
> **공공성** 측면에서는 거래 전에 사기 신호를 경고해 **중고거래 사기를 예방**하고, 누구나 무료로 적정 시세를 확인할 수 있어 정보 비대칭을 줄입니다. 음성과 대화로 쓸 수 있어 디지털에 익숙하지 않은 분도 사용할 수 있습니다.
> **상업성** 측면에서는 안전결제·검수 서비스 제휴 수수료, 프리미엄 알림 구독, 리퍼·매입 업체 대상 시세 데이터 판매를 수익 모델로 생각하고 있습니다.

★ 공공성 또는 상업적 가치

## 10. 개선점과 향후 계획 · 40초 (A) — 슬라이드 13~14

> 이 프로젝트는 2022년 캡스톤을 2026년 기준으로 다시 만든 것입니다. 지원이 끝난 기술을 전부 최신으로 바꿨고, 다른 모델이 섞이던 검색 정확도와 이메일이 노출되던 보안 문제를 고쳤습니다.
> 한계도 있습니다. 당근은 자동 수집을 차단해서 **우회하지 않고 제외**했고, RAG 문서가 아직 적습니다.
> 다음 단계로는 마켓 공식 제휴, 벡터 검색 기반 RAG, 그리고 **매물 사진으로 상태와 가품을 판별**하는 기능을 계획하고 있습니다.

> 흩어진 중고 매물을 한 번에, 그리고 안전하게. 애플픽이었습니다. 감사합니다.

## 12. 예상 질문과 답변

| 질문 | 답변 |
|---|---|
| 데이터는 진짜인가요? | 번개장터 실제 매물을 수집하고 있고, 시연 안정성을 위해 샘플 데이터를 함께 넣었습니다. 화면에는 '샘플 데이터' 배지가 붙고, AI도 샘플이 섞이면 스스로 밝힙니다. |
| 당근은 왜 없나요? | 당근이 자동 수집을 차단하고 있어서, 우회하지 않고 제외했습니다. 수집 소스를 끼워 넣는 구조라 제휴나 공식 API가 생기면 바로 추가할 수 있습니다. |
| 크롤링은 법적으로 괜찮나요? | 공개된 매물 정보만, 요청 간격을 두고 수집하고, 차단된 곳은 우회하지 않습니다. 실제 서비스로 간다면 마켓과의 제휴가 전제라고 생각합니다. |
| AI가 틀린 가격을 말하면요? | 가격과 매물 숫자는 반드시 도구 결과만 쓰도록 지시했고, 화면에도 도구 결과 카드가 따로 나와서 사용자가 직접 확인할 수 있습니다. |
| RAG는 어떻게 구현했나요? | 중고거래 가이드 문서를 소제목 단위로 나눠 LangChain 검색기 인터페이스로 만들었고, 한국어 띄어쓰기 차이를 고려한 BM25 검색을 씁니다. 다음 단계로 임베딩 기반 벡터 검색을 계획하고 있습니다. |
| 사기 신호는 어떻게 판단하나요? | 시세 대비 가격 수준을 6단계로 분류하고, 매물 설명에서 선입금·외부 메신저·급처 같은 위험 표현과 애플케어·풀박스 같은 긍정 표현을 찾습니다. |
| 비용은 얼마나 드나요? | 소형 모델(gpt-5.4-mini)을 써서 질문 하나에 몇 원 수준입니다. 모델과 추론 강도는 설정 파일에서 바꿀 수 있습니다. |
| 응답이 왜 10초나 걸리나요? | 한 질문에 도구를 2~4개 연속으로 실행하기 때문입니다. 그 대신 실행 과정을 실시간으로 보여줘서 기다리는 동안 무엇을 하는지 알 수 있게 했습니다. |
